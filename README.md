# Vacation Offers Manager

Aplication developed in Python for managing, filtering, and organizing holiday offers. It includes custom validation layers, an automated test suite, and an interactive Streamlit user interface.

## Note
This project is currently a work in progress (WIP). New features and improvements are being added continuously.

## Features

- Add, view, and modify vacation offers.
- Advanced filtering by time intervals, price ranges, destinations, and duration.
- Reports for average prices and destination statistics.
- Data validation for dates (DD.MM.YYYY) and prices.
- Interactive Streamlit web interface.
- Automated unit tests.

## Tech Stack

- Language: Python 3.x
- UI Framework: Streamlit
- Data Manipulation: Pandas
- Testing: Python unittest / Custom assertions
